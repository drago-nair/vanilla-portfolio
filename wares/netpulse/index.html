NetPulse

Real-time Network Intrusion Detection System 2025 · Python · Scapy · Flask · SQLite

What is NetPulse?

NetPulse is a real-time Network Intrusion Detection System built from the ground up in Python. It sniffs live network traffic via Scapy and runs a modular detector pipeline to flag malicious activity — no cloud dependencies, no paid APIs, just raw packet inspection.

Architecture

NetPulse follows a pipeline architecture where raw packets flow through discrete detection stages. Each detector operates independently and raises severity-ranked alerts that feed into a central reporting engine.

Packet Capture → Feature Extraction → Detection Pipeline → Alert Engine → Dashboard

Detection Modules

Port Scan Detection

Tracks connection attempts across port ranges using SYN packet analysis. Flags horizontal scans (one attacker, many ports) and vertical scans (one port, many targets) with configurable thresholds.

SSH Brute-Force Detection

Monitors SSH authentication failure rates per source IP. Uses a sliding window counter — if failed attempts exceed the threshold within the window, an alert fires with the offending IP and attempt count.

ARP Spoofing Detection

Watches for ARP reply anomalies — specifically, IP-to-MAC mappings that suddenly change mid-session. A classic sign of an attacker positioning themselves as a man-in-the-middle.

DNS Tunneling Detection

Applies entropy analysis to DNS query payloads. Legitimate DNS queries have low entropy (predictable domain names). Tunneling tools pack encrypted data into DNS — the entropy spike is the signal.

Dashboard

A lightweight Flask web dashboard provides live monitoring: real-time alert feed, severity breakdowns, per-detector statistics, and a timeline of recent events. Designed for at-a-glance situational awareness during active monitoring sessions.
