This Portfolio

Hand-built. No frameworks. No build step. 2025–2026 · HTML · CSS · JavaScript

Why vanilla?

Every part of this site — the bento grid, the note cards, the auto-updating counters, the project thumbnails — is hand-written HTML, CSS, and JavaScript. No React. No Tailwind. No npm install. Just three files that ship directly to the browser.

The philosophy is simple: a personal portfolio doesn't need a JavaScript framework. It needs to be fast, readable, and yours. Every line of CSS was chosen. Every interaction was deliberately coded. Nothing was generated by a CLI wizard.

Design System

Blood Rose Palette

A dark, high-contrast theme built around four core colors: #e11d48 (Blood Rose accent), #22c55e (green highlights), #f59e0b (amber warnings), on a near-black #080e0d background. The palette was chosen to feel technical, sharp, and just slightly aggressive — fitting for a security researcher's home on the web.

Bento Grid Layout

The homepage uses a CSS Grid bento layout — asymmetric card tiles of varying sizes that snap into place. Each tile has its own character: the streak counter, the project showcase, the lab videos, the about section. Hover lifts and green glow effects give the grid a tactile, responsive feel without animation bloat.

Auto-Updating Counters

The note count and project count on the homepage aren't hardcoded. A small inline script fetches the note index JSON and counts DOM-resident project cards at page load — so adding a note or project automatically updates the numbers. Zero manual bumping.

RSS Feed

A static RSS 2.0 feed regenerates from the note index. Feed readers pick up new security write-ups as they're published. Built with a rebuild script — run one command, the feed is current.
