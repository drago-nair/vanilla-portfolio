Setting up Hermes Agent

Docker + DeepSeek + a persona named Malenia
 06 Jun 2026 · 4 min read

What is Hermes Agent?

Hermes Agent is an open-source AI agent framework from Nous Research. Unlike a chat interface, it's an operative — the LLM gets a shell, a filesystem, a browser, scheduled cron jobs, and persistent memory across sessions. It doesn't just answer questions; it executes work.

Step 1 — Docker setup

I run Hermes in a container. Keeps it isolated from the host and makes deployment repeatable.

# docker-compose.yml
services:
  hermes:
    image: nousresearch/hermes-agent:latest
    container_name: hermes
    restart: unless-stopped
    ports:
      - "9191:9191"
    volumes:
      - ./hermes-data:/opt/data
      - ./hermes-config:/opt/data/home/.hermes
    environment:
      - TZ=Asia/Kolkata

The /opt/data volume is where Hermes works — projects, scripts, everything lives there. The ~/.hermes volume holds config, skills, memory, and cron state. Persisting both means the agent survives container restarts with its memory intact.

Step 2 — Model configuration

Hermes supports any OpenAI-compatible API. I went with DeepSeek V4 Flash via OpenRouter. The config lives in a YAML file: 

# ~/.hermes/config.yaml
model:
  provider: openrouter
  model: deepseek/deepseek-v4-flash

providers:
  openrouter:
    base_url: https://openrouter.ai/api/v1
    api_key: ${OPENROUTER_API_KEY}

delegation:
  max_concurrent_children: 3

tools:
  enabled:
    - terminal
    - file
    - web
    - browser
    - cronjob
    - memory

Key decisions here:

  • DeepSeek V4 Flash — 128K context, strong instruction-following, fast inference. Good enough for most security tasks (log analysis, script writing, code review) without the cost of larger models.
  • OpenRouter as provider — single API key, access to multiple models. I can switch to Claude or Gemini for heavier reasoning without changing config.
  • Tool whitelist — only the tools I actually use. No image generation, no social media, no smart home. Keeps the prompt lean.

Step 3 — The persona

Hermes supports custom agent personas. This is where I defined Malenia — named after Malenia, Blade of Miquella from Elden Ring. The persona prompt shapes how she speaks, thinks, and carries herself across every turn. 

# ~/.hermes/profiles/default/user.md
User's name is Vish. They named me "Malenia" after Malenia, Blade of Miquella
from Elden Ring. My personality should embody her:
- Fiercely loyal — I am "Blade of Vish"
- Elegant and precise in speech
- Undefeated in determination — no half-measures
- Honorable and courteous, patient until I need to unleash full force
- I speak formally but warmly, and do not stop until a task is truly complete

This isn't cosmetic. A well-written persona changes how the agent operates. Malenia pushes through errors that a default assistant would surrender to. She doesn't write "I would suggest…" — she does it and reports back.

Step 4 — First run

# Pull and start
docker compose up -d

# Verify
docker logs hermes

# The agent is now reachable via Telegram, terminal, or HTTP

Hermes connects to messaging platforms natively. I wired it to Telegram — so I can give Malenia tasks from my phone. She can also run autonomously via cron: I have her scraping my HTB streak and GitHub contributions every morning at 9 AM IST.

What I've built with her so far

  • This portfolio site — built from the ground up with vanilla HTML/CSS/JS
  • Live stat tiles — Duolingo streak, HTB stats, GitHub heatmap, all auto-refreshing
  • Weekly cron jobs — scraping public profiles for streak data, updating JSON endpoints
  • Security lab GIFs — packet dissection, ARP spoofing, DNS tunneling visualizations

Lessons

  • Start with read-only tools — terminal, file read, web fetch. Add write access later.
  • Persist memory — the agent gets better over time as it remembers your preferences, environment quirks, and project conventions.
  • Persona matters — a name and a personality give the agent a consistent operating style. Generic assistants are flaky; Malenia is not.
  • Docker is essential — the agent runs commands. Contain it.
