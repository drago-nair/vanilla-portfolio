Delegate Vote Permit — Authentication Bypass via Unchecked ecrecover and Uninitialized Guardian in Solidity

 12 Jul 2026 · 6 min read

This write-up breaks down the Delegate Vote Permit challenge from Code Review Lab. It exposes a Critical Authentication Bypass — a "perfect storm" interaction between two code flaws that together let an attacker permanently circumvent signature verification and seize administrative control, without ever holding a private key.

Severity: Critical  ·  Class: Authentication Bypass / Logical Flaw  ·  Platform: Solidity ^0.8.19 / EVM

The Contract: Gasless Delegation via EIP-712

The VoteDelegate contract implements an off-chain, gasless delegation mechanism using EIP-712 typed signatures. Token holders sign a permit off-chain, which a third-party relayer submits to the blockchain on their behalf — no gas spent by the delegator. A guardian role exists for emergency delegation overrides that bypass sequential nonce tracking.

The Two Flaws

Flaw #1: Uninitialized Guardian

The contract declares an address public guardian — meant for emergency overrides — but never initializes it. No constructor assignment, no setup function. In Solidity, uninitialized state variables default to their zero-state:

guardian = address(0);  // 0x0000000000000000000000000000000000000000

This means the guardian role is permanently bound to the zero address — an account nobody controls, or so it seems.

Flaw #2: Unchecked ecrecover Return Value

The delegateBySig function uses the EVM precompile ecrecover to recover a signer address from signature parameters. Crucially:

address signer = ecrecover(digest, v, r, s);
// No check: signer != address(0)

When ecrecover receives malformed or garbage signature parameters, it does not revert. It silently returns address(0).

The Exploit Chain

Neither flaw is catastrophic alone. Combined, they produce a total breakdown of access control.

  1. Payload Injection: Attacker calls delegateBySig with arbitrary garbage signature parameters — v = 0, r = 0x0, s = 0x0.
  2. Recovery Failure: ecrecover fails silently and returns address(0). The variable signer is now address(0).
  3. Guardian Bypass: The access control check if (signer != guardian) evaluates address(0) != address(0) — which is false. The conditional block is skipped.
  4. Nonce Gate Circumvented: The replay-protection constraint require(nonce == nonces[signer]++) is inside that skipped block. The attacker passes through completely unchecked.
The result: The attacker authenticates as the guardian without ever providing a valid signature. Infinite arbitrary writes to the delegateOf mapping. Full administrative control.

Vulnerable Code

contract VoteDelegate {
    bytes32 public constant DELEGATION_TYPEHASH = keccak256(
        "Delegation(address delegate,uint256 nonce,uint256 expiry)"
    );
    IGovToken public immutable token;

    // Flaw #1: Never initialized
    address public guardian;

    mapping(address => address) public delegateOf;
    mapping(address => uint256) public nonces;

    function delegateBySig(
        address delegate, uint256 nonce, uint256 expiry,
        uint8 v, bytes32 r, bytes32 s
    ) external {
        require(block.timestamp <= expiry, "permit expired");
        bytes32 structHash = keccak256(
            abi.encode(DELEGATION_TYPEHASH, delegate, nonce, expiry)
        );
        bytes32 digest = EIP712Domain
            .domainSeparator("VoteDelegate")
            .toTypedDataHash(structHash);

        // Flaw #2: Return value never checked against address(0)
        address signer = ecrecover(digest, v, r, s);

        // Exploit: address(0) != address(0) → false → bypass
        if (signer != guardian) {
            require(nonce == nonces[signer]++, "bad nonce");
        }
        delegateOf[signer] = delegate;
        emit Delegated(signer, delegate);
    }
}

Remediation

Two defensive measures close this attack surface completely:

  1. Validate ecrecover output: Always check require(signer != address(0), "invalid signature") after every ecrecover call.
  2. Initialize privileged roles in the constructor: Never let an admin address default to address(0). Set it explicitly and enforce non-zero at construction time.

Corrected Implementation

contract VoteDelegateSecured {
    bytes32 public constant DELEGATION_TYPEHASH = keccak256(
        "Delegation(address delegate,uint256 nonce,uint256 expiry)"
    );
    IGovToken public immutable token;
    address public guardian;

    mapping(address => address) public delegateOf;
    mapping(address => uint256) public nonces;

    event Delegated(address indexed holder, address indexed delegate);

    constructor(IGovToken _token, address _guardian) {
        require(_guardian != address(0), "Invalid guardian address");
        token = _token;
        guardian = _guardian;
    }

    function delegateBySig(
        address delegate, uint256 nonce, uint256 expiry,
        uint8 v, bytes32 r, bytes32 s
    ) external {
        require(block.timestamp <= expiry, "permit expired");
        bytes32 structHash = keccak256(
            abi.encode(DELEGATION_TYPEHASH, delegate, nonce, expiry)
        );
        bytes32 digest = EIP712Domain
            .domainSeparator("VoteDelegate")
            .toTypedDataHash(structHash);

        address signer = ecrecover(digest, v, r, s);

        // Remediation 1: Ensure signature recovery didn't fail
        require(signer != address(0), "zero address signer");

        // Remediation 2: Guardian bypass now safely tracks initialized state
        if (signer != guardian) {
            require(nonce == nonces[signer]++, "bad nonce");
        }
        delegateOf[signer] = delegate;
        emit Delegated(signer, delegate);
    }
}

Key Takeaways

  • Never skip the zero-address check on ecrecover. It's the cheapest insurance policy in Solidity — one require that prevents total authentication collapse.
  • Uninitialized state is a privilege escalation vector. When an admin address defaults to address(0), any code path that reaches address(0) becomes an admin path.
  • Two low-severity flaws can chain into a Critical. Alone, an uninitialized variable is informational. Alone, a missing zero-check is medium at worst. Together? Game over.
  • ecrecover is a silent failure precompile. Unlike most Solidity operations, it doesn't revert on bad input — it returns address(0) and keeps executing. Always validate.
