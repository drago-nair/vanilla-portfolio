Regression & Information Metrics — Deep-Dive Comparisons

 12 Jun 2026 · 5 min read

⚖️ Section 1: Linear Regression vs. Logistic Regression

The fundamental divide in supervised machine learning comes down to one question: are you predicting a number, or sorting into a bucket?

Feature Linear Regression 📏 Logistic Regression 🎢
Primary Task Regression — predicting a continuous, measured numeric value Classification — predicting a discrete, categorical label
Output Range Infinite — any number from −∞ to +∞ Strict probability — a decimal between 0 and 1
Line / Shape A rigid, straight line (flat hyperplane in higher dimensions) A flexible, S-shaped curve (created by the Sigmoid function)
Underlying Math Ordinary Least Squares (OLS) — minimises the squared distance to a straight line The Sigmoid function compresses a straight line's values into a 0-to-1 boundary
Decision Boundary None — the line itself is the exact prediction Yes — uses a threshold (e.g. 0.50) to create a definitive dividing fence

💡 Core Intuition — Student Tracking

Linear Regression: You want to predict a student's exact exam score. The model outputs a number: 84.3.

Logistic Regression: You want to predict whether the student will Pass (1) or Fail (0). The model outputs a probability: 0.84 — an 84% chance of passing. Since 0.84 > your 0.50 threshold, the student is sorted into the "Pass" bucket.

🎲 Section 2: Gini Impurity vs. Entropy

When building Decision Trees, both Gini Impurity and Entropy serve as the tree's internal "sensors" — answering the question: "How mixed up is this group of data?" They behave almost identically on a graph, but they approach chaos from two distinct mathematical angles.

Feature Gini Impurity 🎲 Entropy 😲
Core Concept The Guessing Game — probability of misclassifying an item if you guessed completely at random The Surprise Factor — the amount of absolute disorder, chaos, or uncertainty in the group
Perfect Purity 0.0 — zero chance of a guessing mistake 0.0 — zero surprise; you know exactly what you'll pull out
Maximum Chaos
(50/50 split)		 0.5 — a 50% chance of guessing wrong 1.0 — complete uncertainty; a coin toss

Computational Speed ⚡ Fast — squares are cheap to compute 🐢 Slower — logarithms require more processing power
Typical Usage Default metric in Python's scikit-learn (speed preference) Traditional algorithms (ID3), advanced information theory

💡 Core Intuition — The Marble Buckets

Imagine a bucket with 50 Red and 50 Blue marbles — maximum messiness.

Lens What It Says Score
Gini Pull one marble, put it back, blindly guess the colour of the next — you'll be wrong 50% of the time. 0.5
Entropy Reach in for a marble — you have absolutely no idea which colour you'll get. Total coin toss. 1.0

Now fill the bucket with 100 Red, 0 Blue. Both metrics instantly drop to 0.0 — zero guessing error, zero surprise. Pure order.

🔑 Quick-Reference Cheat Sheet

Question Answer
Predicting a continuous number? Linear Regression
Predicting yes/no, pass/fail, cat/dog? Logistic Regression
Fastest split metric for decision trees? Gini Impurity
Information-theoretic purity metric? Entropy
Gini max value (2-class)? 0.5
Entropy max value (2-class)? 1.0
Both metrics = 0.0 when? The group is 100% one class
Takeaway: Linear Regression draws a line through your data; Logistic Regression draws a line through your data and squashes it into a probability. Gini asks "how often would I guess wrong?" — Entropy asks "how surprised would I be?" Same destination, different journey.
